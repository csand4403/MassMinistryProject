Create or sign up the first auth user for `chases@maryimmaculatechurch.org`, then run:

```sql
INSERT INTO public.app_user (id, parish_id, role)
SELECT u.id, p.id, 'ADMIN'::public.app_user_role
FROM auth.users u
CROSS JOIN LATERAL (
  SELECT id
  FROM public.parish
  ORDER BY created_at
  LIMIT 1
) p
WHERE lower(u.email) = lower('chases@maryimmaculatechurch.org')
ON CONFLICT (id) DO UPDATE
SET parish_id = EXCLUDED.parish_id,
    role = 'ADMIN'::public.app_user_role;
```

If the SQL affects zero rows, the auth user does not exist yet or the email differs in Supabase Auth.

For a test minister login, create/sign up a second auth user, choose an existing `minister.id`, then run:

INSERT INTO public.app_user (id, parish_id, minister_id, role)
